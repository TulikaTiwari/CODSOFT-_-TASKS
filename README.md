## Tasks Completed

### Task 1: Number Game
A Java-based number guessing game in which the user attempts to guess a randomly generated number.

### Task 2: Student Grade Calculator
Calculates total marks, average percentage, and grade based on marks entered by the user.

### Task 3: ATM Interface
Simulates basic ATM operations, including balance checking, depositing money, and withdrawing money.

### Task 4: Quiz Application with Timer
A multiple-choice quiz application that displays questions, accepts answers, calculates the score, and includes a timer.

### Task 5: Student Course Registration System
Allows students to view available courses, register for courses, and remove registered courses.

## How to Run a Task

1. Open the folder of any task.
2. Open a terminal or command prompt in that folder.
3. Compile the Java file:

```bash
javac FileName.java
```

4. Run the program:

```bash
java FileName
```

Replace `FileName` with the actual Java file name inside that task folder.
